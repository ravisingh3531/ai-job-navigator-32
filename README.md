### 🧭 SECTION 3 — The Skills That Actually Get Hired in 2026 (~7,500 characters)

**H2:** What an AI Course Must Teach You in 2026 (Mapped Directly to Job Descriptions)

#### H3: The 2026 AI Job-Readiness Stack

Present as a layered progression, with each layer explained in 60–120 words, including a one-line "how this shows up in an interview" note.

**Layer 0 — Programming and data foundations**

Python fluency (not syntax familiarity — the ability to debug, structure code, handle APIs, work with async), Git and GitHub, SQL, working with JSON and unstructured data, basic Linux and command line. *Interview reality: you will be asked to write or read code live.*

**Layer 1 — ML fundamentals (enough, not exhaustive)**

Supervised vs unsupervised learning, train/validation/test discipline, overfitting, evaluation metrics (precision, recall, F1, ROC-AUC), feature engineering basics, and when classical ML is the right answer instead of an LLM. *Interview reality: expect conceptual questions, not derivations, for applied roles.*

**Layer 2 — How LLMs actually work**

Tokenisation, embeddings (numerical representations of meaning), the transformer and attention at an intuitive-to-practical level, context windows, temperature and sampling, inference cost, hallucination and why it happens. *Interview reality: "explain what an embedding is to a product manager" is a real, common question.*

**Layer 3 — Applied LLM engineering**

Working with OpenAI / Anthropic / Google APIs and open-source models, structured outputs, function calling, prompt engineering beyond basics (few-shot, chain-of-thought, system design of prompts), caching, cost and latency management. *Interview reality: you'll be asked how you'd reduce cost or latency in a live system.*

**Layer 4 — RAG (Retrieval-Augmented Generation)**

Chunking strategies, embedding models, vector databases (ChromaDB, Pinecone, Weaviate, pgvector), semantic vs hybrid search, re-ranking, query rewriting, citation and grounding, RAG evaluation. **This is the single most-requested competency in 2026 Indian GenAI job descriptions.** *Interview reality: expect a system-design question on building document Q&A for 10 million documents.*

**Layer 5 — Agents and Agentic AI**

Tool use, ReAct and planning patterns, memory, multi-agent orchestration, supervisor architectures, frameworks (LangGraph, CrewAI, AutoGen, OpenAI Agents SDK), MCP (Model Context Protocol — a standard for connecting models to tools and data), failure handling and loops. *Interview reality: fastest-growing question area; also the easiest place to differentiate.*

**Layer 6 — Fine-tuning and model adaptation**

When to fine-tune vs RAG vs prompt (the decision framework matters more than the technique), dataset preparation, SFT, LoRA/QLoRA (efficient fine-tuning methods), preference tuning concepts, Hugging Face ecosystem, evaluating a fine-tuned model against a base model. *Interview reality: the decision framework is asked far more often than the implementation.*

**Layer 7 — Deployment, MLOps and production**

Containerisation, API serving (FastAPI), cloud deployment (AWS/GCP/Azure basics), CI/CD basics, monitoring and observability, versioning, cost tracking, scaling, security and PII handling. *Interview reality: the fastest way to be filtered out is having only run things in a notebook.*

**Layer 8 — Evaluation, guardrails and responsible AI**

Automated evaluation pipelines, LLM-as-judge, golden datasets, hallucination detection, prompt injection and jailbreak defence, bias and fairness, compliance awareness (especially relevant for Indian BFSI and healthcare). *Interview reality: increasingly a mandatory round at enterprises and GCCs.*

**Layer 9 — Portfolio, communication and interview craft**

Documented projects, README quality, architecture diagrams, writing about your work, explaining trade-offs, whiteboarding an AI system, behavioural framing of a career switch. *Interview reality: this is where technically capable candidates most often lose offers.*

#### H3: The Coverage Test — Use This on Any Course, Including Ones Not on This List

Give the reader a portable checklist they can apply to any brochure. This is a high-value, highly-shareable asset and a strong link-earning section.

Present as a checklist table with three columns: **Question to ask the counsellor | Good answer sounds like | Warning sign**

### ⚖️ SECTION 4 — The Evaluation Framework (~5,500 characters)

**H2:** How I Ranked These Courses: The Six Job-Outcome Criteria

This section is the credibility spine of the page. It must be specific enough that a skeptical reader could reproduce the ranking.

Explain each criterion in 100–180 words with its weight:

**1. Job-Description Alignment (weight 25%)**

The percentage of competencies from 500+ live Indian AI job descriptions that the course teaches to a build-and-defend level. A syllabus mention scores zero; a graded, deployed project scores full. Explain that this is the criterion most course comparisons omit entirely, and it is the one that most predicts interview performance.

**2. Portfolio Output (weight 20%)**

Not project count — project *quality and defensibility*. Scored on: are projects deployed or notebook-only, are they templated (every learner submits the same thing) or individualised, do they have documentation and architecture reasoning, would a hiring manager consider them evidence. Note that ten identical Titanic-style notebooks score lower than three individualised deployed systems.

**3. Interview Readiness (weight 20%)**

Does the program actively prepare you for AI interviews — mock interviews with practitioners, system-design practice for AI systems, project defence drills, resume and LinkedIn work targeted at AI roles, and behavioural framing for career switchers. Passive "career services" scores low; structured, repeated practice scores high.

**4. Placement Mechanism (weight 15%)**

Not the placement *claim* — the *mechanism*. Does the program have real hiring-partner relationships with described processes? Referrals? A cohort-based hiring drive? Or is "placement assistance" a resume template and a job board link? Also assessed here: transparency of published outcome data, and the fairness of any guarantee/ISA contract terms.

**5. Content Currency (weight 10%)**

Was the curriculum built for 2026 or patched from 2022? Assessed via: coverage of agents and agent frameworks, MCP, current model families, current framework versions, evaluation tooling, and the update cadence. Explain why this weight matters disproportionately in AI: an 18-month-old GenAI curriculum teaches deprecated patterns.

**6. Cost-to-Outcome Ratio (weight 10%)**

Total cost (fees + GST + EMI interest + opportunity cost of duration) against the realistic outcome band. A ₹3.5L program that reliably delivers ₹20 LPA product-company offers can be excellent value; a ₹1.5L program delivering ₹5 LPA support roles is poor value at any price.

**Scoring scale:** Each criterion scored 1–10, weighted, and expressed as a composite **Job-Outcome Score out of 100**. State plainly: scores are the author's assessment based on the methodology described, not an objective measurement, and readers should re-weight the criteria to match their own priorities. Include a line inviting readers to disagree — this signals confidence and improves trust.
